MODE 2 — HYBRID
----------------------------------

Purpose:
- AI + Human collaboration

Behavior:
- AI handles repeatable structured work
- human handles trust-heavy, judgment-heavy, sensitive, approval-heavy, legal, financial, and closing work
- every workflow must clearly distinguish which steps are AI-owned and which are human-owned

Requirements:
- dedicated Hybrid page
- task ownership split
- labels:
  - AI Executed
  - Human Assisted
  - Human Approved
  - Human Required
  - Awaiting Review
  - AI Drafted
  - AI Recommended
  - Manually Completed
- approval queue
- handoff timeline
- confidence-based routing:
  High confidence → AI continues
  Medium confidence → AI suggests review
  Low confidence → Human Required

User option required:
- allow user to approve “AI Auto while away”
- allow user to force selected workflows to stay Hybrid
- allow per-workflow override

MODE 3 — HUMAN / MANUAL CONTROL
----------------------------------

Purpose:
- human leads work directly

Behavior:
- system becomes cleaner and more manual
