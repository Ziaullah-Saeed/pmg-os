2. REQUIRED THREE-MODE OPERATING MODEL
The system must run in three true operational modes, not just a cosmetic switch. These modes must affect workflow behavior, agent authority, UI structure, approval logic, and task ownership. 
Mode A — AI MODE / AI AUTO
Use when the user is away or wants autonomous operation.
Behavior
•	AI agents perform all eligible work automatically 
•	workflows continue 24/7 
•	AI researches, scores, routes, drafts, schedules, monitors, follows up, logs, reports, updates library, and triggers tasks 
•	only high-risk actions are paused for approval if policy requires it 
UI requirements
This mode must open a dedicated AI Auto environment showing:
•	live AI task queue 
•	autonomous workflows in progress 
•	active agents 
•	pending approvals 
•	cost usage from wallet 
•	system confidence indicators 
•	escalation events 
•	intervention-needed alerts 
Task ownership
•	AI owns all low-risk and medium-risk repeatable work 
•	humans only review exception queues, legal/financial blocks, and protected approvals 
________________________________________
Mode B — HYBRID
Use when AI and humans collaborate.
Behavior
•	AI performs research, drafts, scoring, routing, suggestions, monitoring, and repetitive execution 
•	human performs approvals, trust-heavy communication, overrides, negotiations, and sensitive final actions 
•	every workflow clearly distinguishes what AI did, what human did, and what is awaiting review 
UI requirements
This mode must open a Hybrid workspace showing:
•	AI-completed tasks 
•	human-assigned tasks 
•	approval queue 
•	task ownership split 
•	workflow timeline with AI/Human markers 
•	confidence-based handoff logic 
•	next action assignments 
Task ownership
Each workflow must declare:
•	AI-owned steps 
•	human-owned steps 
•	shared / review-required steps 
User control
The user must be able to approve AI autonomous continuation when they are away.
There must be an option like:
•	“Enable AI Auto while I am away” 
•	“Require approval before switching to full AI Auto” 
Hybrid must support this escalation path:
Hybrid → user approval → AI Auto
________________________________________
Mode C — HUMAN / MANUAL CONTROL
Use when the human wants direct operation.
Behavior
•	automation is reduced or paused based on policy 
•	AI becomes guide / assistant / recommender rather than executor 
•	user directly performs the work 
UI requirements
This mode must switch the interface to a cleaner manual-control view:
•	less AI noise 
•	more direct controls 
•	more manual forms and operating tools 
•	explicit workflow steps 
•	section-specific manual guides 
Manual guide requirement
In Human mode, every domain must include a manual guide explaining:
•	what the task is 
•	what order to do it in 
•	what fields are required 
•	what outputs are created 
•	what approvals are needed 
•	what happens next

•	account-level permissions 
•	manual exports 
•	CSV uploads

•	admin reconnection 
•	manual field mapping 
•	periodic human review 
•	manual attribution corrections

•	reconciliation of source mismatches 
Therefore, the system must support both:
A. Automatic integration mode
•	OAuth connection

B. Manual integration mode
•	CSV import / export 
•	manual field mapping 
•	manual source assignment 
•	manual lead import 
•	manual sync trigger 
•	manual account refresh 
•	manual reconnection

•	manual attribution correction

This includes paid tools such as LinkedIn Sales Navigator, but is not limited to Sales Navigator. Any standard operational tool used by PMG or a client must be capable of being connected either automatically or manually.
